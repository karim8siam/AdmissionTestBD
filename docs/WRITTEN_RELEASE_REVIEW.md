# Initial written release review — 2026-10-12

This release adds a separate **লিখিত প্রস্তুতি** tab immediately before the past-paper tab. Two independently accessible original PCM sets contain 20 explicit questions each: 7 mathematics, 7 physics, 6 chemistry. BUET practice uses 200 marks/90 minutes; DU practice uses 50 marks/60 minutes. These are custom short practice sets, not full official exam simulations. DU 2025–26's official written section was 40 marks/45 minutes. Biology and language sets, additional papers and chapter-by-chapter written banks are not included in this first release.

Questions require written derivation, branch/constraint checks, physical reasoning, multi-stage conservation, circuit nodal analysis, approximation validity, reaction balancing or functional-group discrimination. They are authored individually rather than generated as numerical variants. Worked solutions and three marking criteria accompany each question. Timing mode hides hints and solutions until submission. Practice mode provides optional hints. Notes, deadlines and rubric self-assessment persist locally in separate track records. No handwriting recognition, automatic examiner marks, uploads or ranking is claimed.

`review_written.py` blocks release on malformed sets, missing worked solutions, duplicate IDs/stems, incorrect mark totals or missing checks. It includes 37 analytic/numeric problem checks and 3 chemistry editorial-only checks; four deliberately invalid fixtures must be rejected. Numerical checks use independent matrix computations, root substitution, quadrature, exhaustive arrangements, geometric/energy residuals, circuit solving, equilibrium residuals and element/charge balances. A pass is **not teacher certification or difficulty calibration against a complete recent corpus**. The qualitative organic and ion-identification checks remain editorial judgments.

`verify_written_ui.cjs` exercises the actual browser modules: 20-question rendering, mode restrictions, note escaping and persistence, reload/resume, navigation confirmation, submission, self-assessed criterion scores, track separation, timer expiry, archive filters, empty results and network retry. Existing engineering and medical/varsity chapter checks also pass.

The engineering tab inside past papers lists eight source entries across six distinct sessions: BUET preliminary 2021–22, 2022–23, 2023–24; CKRUET 2023–24; BUET written compilation 2019–20; and selected public written previews for 2023–24, 2024–25, 2025–26. Recent previews share one source index and require selection of the year there. Labels explicitly distinguish external publications, unchecked scan compilations and partial previews. These entries are **not eight imported full timed papers**, and do not constitute a complete 15-year archive. Every answer and page has not been independently authenticated. Original practice problems are not represented as historical exam questions.

Source provenance is retained in `content/written/research.json` and `data/engineering_archive.json`. Full recent-paper calibration and independent teacher review remain outstanding. Publishing this narrowly described pilot is authorized by the user's instruction to check and upload; expanding the claimed scope without that evidence would be misleading.
